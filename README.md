# SEO Party Skills

Experimental SEO skills for [OpenSEO](https://openseo.so), listed on [SEO.party](https://seo.party).

These aren't official OpenSEO skills. They're ideas for skills that we think people will find useful, usually for a narrower workflow than the core OpenSEO skills cover. Expect more of them over time.

Every skill here uses the OpenSEO MCP server, so you'll need OpenSEO connected to your agent.

## Skills

| Skill | What it does |
| --- | --- |
| [keyword-gap](skills/keyword-gap/SKILL.md) | Finds keywords your competitors rank for and you don't, and groups them into page ideas. |

## Install

Find a skill on [SEO.party](https://seo.party) for install commands for your agent, or install with the GitHub CLI:

```sh
gh skill install every-app/seo-party-skills keyword-gap
```
